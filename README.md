# LED Strip Smart Controller

A professional Flutter + IoT smart LED strip controller built with Flutter, ESP32, FastLED, and MQTT.

## Repository Structure

```text
flutter/
firmware/
docs/
```

## Technology Stack

### Flutter

- Flutter
- Riverpod
- go_router
- Material 3

### Firmware

- PlatformIO
- ESP32-C3
- FastLED
- PubSubClient

### Communication

- MQTT
- HiveMQ Public Broker
