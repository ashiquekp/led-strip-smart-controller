# Lumora

Lumora is a professional Flutter + IoT smart LED strip controller.

## Goals

- Flutter + Riverpod
- ESP32 + FastLED
- MQTT communication
- Professional architecture
- Commercial lighting effects
- Scheduling
- Statistics
- Presets

## Hardware

- Seeed Studio XIAO ESP32-C3
- WS2812B (50 LEDs)

## Broker

HiveMQ Public Broker
